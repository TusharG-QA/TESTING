# Testing Academy - JavaScript Fundamentals

A collection of JavaScript learning examples organized by chapters, covering basics to advanced concepts.

## Chapters

- **Chapter 1: Basics** - Hello World, Node.js runtime inspection, JavaScript commands
- **Chapter 2: JavaScript Concepts** - Variables, data types, type coercion
- **Chapter 3: Identifiers & Literals** - Identifier rules, string/number/boolean literals
- **Chapter 4: JavaScript Concepts** - Const, let, var declarations
- **Chapter 5: Literals** - Integer, floating-point, string, and expression literals
- **Chapter 6: Operators** - Arithmetic, comparison, logical, ternary, increment/decrement operators
- **Chapter 7: If-Else** - Conditional statements, if-else-if ladder
- **Chapter 8: Switch Statement** - Switch-case control flow
- **Chapter 9: User Input** - Taking user input in Node.js
- **Chapter 10: Loops** - For, while, do-while loops
- **Chapter 11: Arrays** - Array operations and methods

## Prerequisites

- [Node.js](https://nodejs.org/)

## Usage

```bash
node Chapter_01_Basics/01_Basics.js
node Chapter_01_Basics/03_JS_Command.js
```

Run any chapter file with Node.js to see the examples in action.
